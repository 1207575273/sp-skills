# 股票/基金行情只读分析

只读拉取行情做分析:实时报价、历史K线、技术指标(MA/RSI/MACD/KDJ)、信号面板(客观统计+指标状态)、上海黄金交易所金价,可出一份自包含 HTML 走势报告。**只读取数 + 本地分析,不含任何交易/下单能力,也不预测涨跌、不推荐买卖标的**——不接券商、不下单,做不到写操作。数据来自民用公开接口(腾讯/东方财富/Yahoo/上金所),非官方 SLA,可能延迟或变动。**分析结果不构成投资建议,盈亏自负。**

命令统一 `node scripts/run-market.mjs <子命令> <参数>`,在本 skill 目录下执行。无需 npm install(零第三方依赖),要求 Node >= 20。

## SOP(按顺序走)

### 步骤 1 - 认代码(必须带市场前缀)

- A股/场内ETF:`sh` + 6位(沪,如 sh600000;ETF 如 sh510300)、`sz` + 6位(深,如 sz000001)
- 港股:`hk` + 5位(如 hk00700)
- 美股:`us` + 代码(如 usAAPL)
- 用户只说名字或裸代码 -> 先跟用户确认是哪个市场、补上前缀,别猜。

### 步骤 2 - 看实时行情

```
node scripts/run-market.mjs quote sh600000 hk00700 usAAPL
```

一次可查多只,给现价、涨跌、涨跌%、最高最低。

### 步骤 3 - 看历史走势(K线)

```
node scripts/run-market.mjs kline sh600000 --limit 60 [--period day|week|month]
```

默认日K、120 根;文本只列最后 30 根,要看完整走势加 `--html` 出图。

### 步骤 4 - 算技术指标

```
node scripts/run-market.mjs indicator sh600000 --type MACD [--n 窗口] [--period day|week|month]
```

`--type` 选 MA/RSI/MACD/KDJ(默认 MA);MA/RSI 的窗口用 `--n`(如 `--type MA --n 20`)。指标基于 K线现算。

### 步骤 5 - 看信号面板(客观状态,不是买卖建议)

```
node scripts/run-market.mjs signals sh600519
```

一屏给出:历史统计(区间涨跌/最大回撤/年化波动率/区间高低)+ 指标当前状态(现价在均线上/下方、RSI 超买超卖区、MACD 最近金叉/死叉、KDJ)+ 指标的传统定义。**只描述已发生的事实和指标状态,不预测涨跌、不替用户判断买卖。** 转达时保留这个边界。

### 步骤 6 - 看黄金(上海黄金交易所)

```
node scripts/run-market.mjs gold
```

上金所 Au99.99(现货黄金,人民币/克)当日分时:现价、当日高低(从分时数据实算)、延时时间。加 `--html` 出分时图。

### 步骤 7 - 出 HTML 报告(要给人看时)

任一出数子命令加 `--html [路径]`,除文本外再生成一份自包含 HTML(可离线打开):报价卡 + 收盘价走势图 + 指标图(黄金则是分时图),板块清晰。`signals --html` 的报告还含信号面板板块。图支持**鼠标悬停**:滑到哪根就显示当天日期与各条线的数值(内联 JS 实现,无外链)。

**归档(强制收敛)**:脚本生成的 HTML **一律落在本 skill 目录下 `reports/`,不写到目录外**。`--html` 不带值 -> 时间戳文件名 `YYYYMMDDHHMMSS_命令_标的.html`(历史积累、互不覆盖);`--html 名字.html` -> 就用这个名字、仍在 `reports/`(即便带了目录也只取文件名,不允许乱放)。要把整个 `reports/` 挪到别处(如 repo 外避免 git 噪音)设环境变量 `MARKET_ANALYZER_REPORTS`。

```
node scripts/run-market.mjs indicator sh600000 --type MACD --limit 120 --html
```

### 步骤 8 - 多只并排对比(一个网页同屏对比)

```
node scripts/run-market.mjs compare sz300750 sh600519 usAAPL [--html 路径]
```

传两个及以上代码,生成一个自包含网页(不给 `--html` 路径时同样按时间戳归档到 `reports/`),每只一栏(响应式:宽屏并排、窄屏堆叠):名称+现价 + 迷你走势图 + 关键统计(区间涨跌/回撤/波动率 + 均线/RSI/MACD 摘要)。

## 红线与必须转达

- **只读不可绕过**:本 skill 没有任何下单/交易能力。用户要买卖 -> 直接说做不到,不要尝试绕。
- **不预测、不荐股**:只给客观数据、指标当前状态、历史统计;不预测涨跌、不推荐买哪只、不给目标价/时间点。signals 面板也只是事实描述。用户要"预测/帮我选/该不该买" -> 说明工具只提供事实,买卖判断由用户自己做。
- **数据仅供参考**:民用公开接口,可能延迟/限频/口径变动;分析不构成投资建议,盈亏自负。转达结论时带上这句。
- **接口偶发失败**:某源挂了会明确报错(超时/限频/代码不存在),照提示换代码或稍后重试,不要静默当无数据。
