# 国内时政/社会热点采集

拉取百度热搜榜的实时榜单(公开接口,免 key),得到当下国内热点的标题与链接。

命令统一 `node scripts/hotspot.mjs <参数>`,在本 skill 目录下执行。

## 用法

```
node scripts/hotspot.mjs                    实时热搜 top 15(默认)
node scripts/hotspot.mjs --top 30           取前 30 条
```

- 输出 JSON:`items` 数组,每条含 `title`/`url`/`isTop`(置顶条目,通常为重大时政)。
- `--tab` 可换榜单(novel/movie/teleplay/car/game),日报场景用默认 realtime 即可。

## 口径与注意

- 榜单只给**标题与链接**,没有正文;需要某条热点的详情/背景时,配合具备网页搜索能力的技能对标题做深挖。
- 置顶条目(isTop)通常是重大时政,日报里优先呈现。
- 民用公开接口,非官方 SLA,结构可能变动;脚本解析失败会明确报错并附原始响应片段,遇到时把报错转告用户。
