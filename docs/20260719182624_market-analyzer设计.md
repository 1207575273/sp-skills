# market-analyzer skill 设计

面向 landray_work_e 的第三个 skill。定位、边界、目录、数据源、第一版范围一次说清,作为写实现计划前的唯一事实源。

---

## 0. 目标(一句话)

用户随口问某只股票/基金"最近怎么走、指标什么样"时,AI 照本 skill 的操作手册跑脚本,从公开行情接口只读拉数据、本地算技术指标,给出一份分析。**只读取数 + 本地分析,不含任何交易/下单能力。**

## 1. 定位与安全边界(不可动摇)

- skill 名:`market-analyzer`(覆盖股票 + 基金 + ETF,与既有 `db-analyzer` 命名对仗)。
- **只读**:只从公开接口拉行情/K线/基本面数据,做本地计算与展示。全程不写任何外部系统。
- **不含交易代码**:第一版一行下单/委托代码都不写,也不接任何券商 API。只读不是靠运行时门禁拦截来保证的,而是"根本没实现"——没有可被误用成下单的执行路径。
  - 对照 db-analyzer 的 safety-gate:那个门禁存在,是因为 db-analyzer 要执行用户输入的任意 SQL,必须拦写操作;本 skill 没有"执行任意用户指令"的入口,门禁无对象可拦,故不做门禁。
- **未来若要接下单**(用户已明确"以后不排除授权买卖"):架构上把"取数分析"与"交易执行"彻底隔离——将来是**新增一个独立、显式解锁的交易模块**,而不是在现有取数代码里预留后门。第一版不为它写任何代码,只在目录规划上保证二者天然可分。
- **免责**:SKILL.md 与 README 均写死——本 skill 提供的是数据与分析,**不构成投资建议,盈亏自负**;数据来自民用公开接口,非官方 SLA,可能延迟或变动。

## 2. 架构与目录(沿用现有 skill 范式)

```
skills/market-analyzer/
  SKILL.md                  给 AI 的操作手册(只读边界 + SOP + 命令清单 + 免责)
  README.md                 给人的部署说明(Node 版本、如何配 settings、免责)
  .gitignore                护住 settings.yaml / data/portfolio.yaml 等私有数据
  package.json              尽量零第三方依赖(Node 18+ 自带 fetch);有 test 脚本
  config/
    settings.example.yaml   数据源开关 / 超时 / 默认市场 / 持仓账本路径(模板)
    settings.yaml           真实偏好(gitignore;公开接口无需密钥)
  lib/
    http.mjs                带超时 + 日志打点的公开接口 GET 封装
    sources/
      tencent.mjs           实时报价:A股/港股/美股/场内基金 一个源全覆盖
      eastmoney.mjs         A股 / 场内基金 历史K线
      yahoo.mjs             美股 / 港股 历史K线(+ 未来基本面)
    indicators.mjs          MA/MACD/RSI/KDJ 纯计算(无网络,最好测)
    indicators.test.mjs
    report.mjs              统一数据结构 -> 单文件自包含 HTML(内联 CSS + 内嵌 SVG 走势图)
    report.test.mjs
  scripts/
    run-market.mjs          唯一命令入口,子命令分发
    run-market.test.mjs
```

第一版**不做** `dist/` 打包(零依赖,无东西可 bundle;将来发 sp-skills 再说),**不做** `data/` 持仓目录(portfolio 功能留到后续批次)。

### 单元职责

- `http.mjs`:唯一出网点。负责超时、UA、错误归一化、每次调用打点(源/URL/状态/耗时)。其它模块不直接 fetch。
- `sources/*.mjs`:各数据源适配器,把"某市场某代码"翻译成该源的请求,解析回统一结构 `{ symbol, market, ... }`。互不依赖。
- `indicators.mjs`:纯函数,输入 K线数组,输出指标序列。无 IO、无网络,TDD 主战场。
- `report.mjs`:纯渲染。输入统一数据结构,输出单文件自包含 HTML 字符串(内联 CSS + 内嵌 SVG 走势图,无外网依赖)。不做 IO(写盘由 run-market 负责)、不做网络,可单测。
- `run-market.mjs`:参数解析 + 子命令分发 + 结果输出(文本到 stdout;带 --html 时调 report.mjs 渲染并写盘);不含业务算法(算法在 indicators,取数在 sources,渲染在 report)。

## 3. 数据源方案(按数据源分,不按市场分)

关键点:一个腾讯公开接口就能同时报 A股/港股/美股/场内基金的实时价,所以按**源**分适配器(2-3 个)而非按市场分(4 个)。全部免费民用公开接口、无需注册 key。

| 数据源 | 覆盖 | 用于 |
|---|---|---|
| 腾讯行情 | A股 / 港股 / 美股 / 场内基金 实时报价 | `quote` |
| 东方财富 | A股 / 场内基金 历史K线 | `kline`(A股/基金) |
| Yahoo Finance | 美股 / 港股 历史K线(+ 未来基本面) | `kline`(美股/港股) |

代码前缀约定(第一版实现,写进 SKILL.md 供 AI 拼装):A股 `sh600000`/`sz000001`,港股 `hk00700`,美股 `usAAPL`,场内基金 `sh510300`。

注意:上表接口的确切 URL、参数、字段名以**实现时 CLI 实跑校准为准**,不照搬记忆(民用接口口径会变;遵循项目硬约束"验证以 CLI 实跑为准")。

## 4. 命令接口

唯一入口 `node scripts/run-market.mjs <子命令> <参数>`,在本 skill 目录下执行。

第一版实现(B 范围):

```
run-market.mjs quote <代码...>                     实时报价,可一次多只
run-market.mjs kline <代码> [--period day|week|month] [--limit N]   历史K线
run-market.mjs indicator <代码> --type MA|MACD|RSI|KDJ [--period ...]  技术指标(基于 kline 算)
run-market.mjs --list-sources                       列出已启用的数据源与覆盖市场
--help                                              全部子命令与选项
```

通用选项 `--html [路径]`:任一子命令带它,除 stdout 文本外额外生成一份自包含 HTML 报告(默认写到 skill 目录下 `report.html`,可指定路径),按板块排版、含 SVG 走势图;不带则只出文本。详见第 4.1 节。

留桩(第二版,SKILL.md 标注"规划中",执行即返回一句"尚未实现,规划中"):

```
run-market.mjs fundamental <代码>                   基本面:财报/估值
run-market.mjs portfolio                            读本地账本 + 拉实时价 = 盈亏
```

## 4.1 HTML 报告输出

- **单文件自包含**:一份 `.html`,内联 CSS、内嵌 SVG,禁任何外网 CDN/字体/脚本 —— 双击离线可开、可随意拷走。
- **板块清晰**:报价板块(数字卡片:现价/涨跌幅/涨跌额)、K线板块(SVG 走势图 + 关键数据)、指标板块(指标线 + 当前值)。跑哪个子命令就渲染哪些板块,数据缺的板块不出现。
- **走势图**:内嵌 SVG 自绘,收盘价走势折线为主、指标叠加线;涨跌配色按市场习惯——A股/港股红涨绿跌,美股绿涨红跌,以数据 market 字段区分。
- **实现纪律**:渲染代码写在 `report.mjs`;实现时用 `frontend-design`(防通用 AI 味、走干净克制风)与 `dataviz`(坐标轴/配色/网格规范)两个 skill 校准审美,不随手糊 CSS。

## 5. 数据流

用户提问 -> AI 读 SKILL.md 选子命令 -> `run-market.mjs` 解析参数、按代码前缀判定市场、选对应 source -> `http.mjs` 拉取(打点)-> source 解析成统一结构 -> (indicator 再过 `indicators.mjs` 纯计算)-> 文本输出到 stdout;若带 `--html`,统一结构再过 `report.mjs` 渲染成自包含 HTML 写盘,stdout 附上报告文件路径。

## 6. 错误处理

- 网络超时:提示可调 `--timeout`,附源与耗时。
- 接口非 200 / 限频:明确报"数据源 X 暂时不可用或被限频",建议稍后或换源。
- 代码不存在 / 市场判不出:提示代码前缀规范,别静默返回空。
- 每个失败分支先打点再抛(日志先行,WAL 理念)。

## 7. 测试策略

- `indicators.mjs`:纯函数,严格 TDD——用已知输入输出校验 MA/MACD/RSI/KDJ(Red -> Green -> Refactor)。
- `run-market.mjs`:参数解析、市场判定、子命令分发做单测(mock 掉 sources,不真出网)。
- `report.mjs`:纯渲染,单测断言产出的 HTML 含各板块标题与关键数值、含内嵌 `<svg>`、且不含任何 `http(s)://` 外链(自包含验证)。
- `sources/*.mjs`:各留一条**冒烟实跑**(真拉一个真实代码),验证接口口径没变;冒烟不进常规单测门禁(依赖外网)。
- 收尾以 CLI 实跑 `node --test` / vitest 退出码为准,不信 IDE 诊断、不信 subagent 自报。

## 9. 全局约束(继承项目 CLAUDE.md)

- 命名业务语义、无 emoji、无 § 类西文符号;状态用 [PASS]/[FAIL] 等,箭头 `->`。
- 日志先行:关键动作(每次外部调用、每个失败分支)先打点后执行。
- Node 18+(用内置 fetch);争取零第三方依赖。
- 平台机制不污染资产:SKILL.md 只自然描述"运行 scripts/run-market.mjs 的某子命令",不写平台内部工具名。
- HTML 报告单文件自包含:内联 CSS、内嵌 SVG,禁任何外网 CDN/字体/脚本(离线可开、可移植)。
- 真实配置永不入库(.gitignore 护住);本 skill 无内网凭证,天然干净,后续可并入公开的 sp-skills。
